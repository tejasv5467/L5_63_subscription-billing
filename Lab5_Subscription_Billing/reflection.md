# Reflection — Static Code Analysis

## 1. What did you learn from static code analysis?

Static code analysis helped identify syntax, formatting, maintainability, and potential security issues without requiring the program to execute. Tools such as Pylint, Flake8, and Bandit provide different perspectives on code quality.

## 2. What issues did you identify and fix?

I worked on correcting indentation and syntax errors, improving code formatting, removing unused imports, and adding documentation to functions. I also reviewed input validation and HTML rendering in the subscription billing system.

## 3. How did the tools complement each other?

Pylint checks code quality, conventions, and potential programming errors. Flake8 checks style violations and common errors. Bandit focuses on potential security issues in Python code. Using all three provides broader coverage than relying on a single tool.

## 4. What would you improve in the future?

I would add automated unit tests, improve input validation, test malformed webhook payloads, review security findings individually, and integrate static analysis into a continuous integration workflow.
